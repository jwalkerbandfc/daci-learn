Questions to think about

Which is the right file?

Who has the file open?

Why do I have another copy of this file in my emails?

With OneDrive, Teams and SharePoint there is one file. People share a link to it and work on it together, and older versions are saved automatically. No more “FINAL v2”.

Three things. One simple idea.

Each of the three apps has its own job. Knowing which is which tells you where a file should live.

Mine

OneDrive

My files and work I’m developing.

Ours

Microsoft Teams

Where a team communicates and works together.

Behind the Team

SharePoint

Stores and manages the shared files you work with through Teams. Can also be used directly for wider organisational content.

Teams and SharePoint are closely connected. Files you work with in a standard Teams channel are stored in SharePoint.

From draft to everyone

An example of one HR policy moving from a personal draft to the whole organisation.

Teams · OursHR TeamThe HR team works on the draft policy together in their Teams space.
Stored behind TeamsHR Team SharePoint siteThe draft saves automatically to the team’s SharePoint site.
Published for everyoneStaff intranet / HR policiesThe final policy is published so everyone sees the latest version.

OneDrive is for your own draft, before it becomes team-owned.

Activities›2. Upload to OneDrive

Make a folder in your OneDrive and put all six practice files in it.

What to do

1

Open OneDrive. In your web browser go to office.com, sign in with your work account, then choose OneDrive from the app list.

2

Select + Add new then Folder, and call it:

Microsoft 365 Practice
3

Open the new folder by clicking its name.

4

Select + Add new then Files upload. Go to your Downloads folder, select all six practice files, and choose Open.

Tip: hold Ctrl and click to pick several files at once. You can also drag the files from File Explorer straight into the browser window.

Check: you should end up with these six files

Can you see all six files inside Microsoft 365 Practice? Tick each one off as you find it.

Activities›3. Share, don’t send

Instead of emailing a copy, share a link to the one file. Work with the person next to you: one of you is Person A, the other is Person B.

Person A

1

In OneDrive, open Microsoft 365 Practice and find Personal_Working_Notes.docx.

2

Hover over the file and select the share icon, or right-click it and choose Share.

3

Type your partner’s name and pick them from the list.

4

Check the permission says Can edit. If not, select the pencil icon and change it. Then select Send.

Person B

1

Open the shared file. Use the link in the email you receive, or go to OneDrive and select Shared on the left.

2

Add your name.

3

Add one sentence underneath.

Check: can you both see the changes? You’re both working on the same file. There’s no second copy sitting in anyone’s inbox.

Activities›4. Fix a mistake

Break it, then recover it. OneDrive keeps earlier versions of your files, so a mistake is easy to undo.

Steps

1

Open Personal_Working_Notes.docx.

2

Delete a section, for example everything under Current thoughts.

3

Let the change save. Wait a few seconds until the top of the window says Saved.

4

Go back to OneDrive.

5

Right-click the file (or select the three dots …) and choose Version history.

6

Find an earlier version from before you deleted the section.

7

Select the three dots next to it and choose Restore.

Check: has the original content returned? Open the file again to see.

You can also do this inside Word: File › Info › Version History. If you notice straight away, Ctrl + Z undoes your last change.

Activities›5. Teams and SharePoint

See for yourself that a Teams channel’s files and its SharePoint site are the same files in two places.

Use a Team you already belong to.

Steps

1

Open Microsoft Teams.

2

Select Teams on the left, then open a Team and a standard channel (for example General).

3

Open the channel’s Shared tab at the top. In some versions this is called Files.

4

Look at the files and pick one to remember.

5

Open the same location in SharePoint. Select … or Open in SharePoint at the top of the file list.

6

Find the same file again in the SharePoint window.

Same file, two views. Teams is where you talk and work. SharePoint is where the file actually lives.
