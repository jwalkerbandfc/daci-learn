    Blender Modelling with Modifiers and Topology

    You can already find your way around Blender and shape meshes with Extrude, Inset, Bevel and Loop Cut. Now learn to model smarter: build shapes non-destructively with modifiers, and arrange your edges so that models smooth, shade and bend cleanly.

    Start with the warm-up Jump to the stack lab

    Learning outcomes

    By the end you will be able to:

    • explain what a modifier is and why non-destructive modelling is useful;
    • add, reorder, hide, apply and remove modifiers in the modifier stack;
    • use the Mirror, Subdivision Surface, Solidify, Array, Bevel and Boolean modifiers, and choose suitable settings for each;
    • predict how changing the order of the modifier stack changes the result;
    • recognise quads, triangles, n-gons, poles and edge flow, and fix common topology problems;
    • control smooth shading with Shade Smooth, Shade Auto Smooth and normals;
    • model precisely using Proportional Editing, snapping, measurements and reference images;
    • combine several modifiers to build a finished model in Blender.

    What is a modifier?

    A modifier is an operation that Blender applies on top of your mesh, automatically and live. Your original mesh stays untouched underneath, so you can change the settings, switch the modifier off or remove it whenever you like. It is like an adjustment layer or a filter in an image editor: the original is still there.

    ✂ Destructive modelling

    Tools such as Ctrl+B or E change the mesh directly.

    • The change becomes part of the mesh straight away.
    • To change your mind you undo or remodel.
    • Both sides of a symmetrical model must be built by hand.

    🔧 Non-destructive modelling

    Modifiers calculate the result from the original mesh every time.

    • Change settings, such as bevel width, at any time.
    • Hide, reorder or remove a modifier without losing work.
    • Model half a chair and let Mirror build the other half.

    ↺Change your mind

    A client wants thicker walls? Change one Solidify value instead of remodelling.

    ½Do less work

    Model half and mirror it, or one post and array it. Edit once, update everywhere.

    ◇Stay light

    Edit a simple low-poly cage while Subdivision Surface shows the smooth result.

    ⚗Experiment safely

    Toggle modifiers on and off to compare ideas without risking your mesh.

    Good to know

    Hover over the panel

    Modifier shortcuts such as Ctrl+A (apply) act on the modifier panel under your mouse pointer. Over the 3D viewport, the same keys do something else.

    Blender 4.1 changed smoothing

    The old Auto Smooth checkbox has gone. Use Shade Auto Smooth, which adds a Smooth by Angle modifier. Older tutorials may still show the checkbox.

    Using a Mac?

    Save and undo use Cmd, and Alt is labelled Option. Modelling shortcuts such as Ctrl+2 still use Ctrl.

    Save versions

    Before applying modifiers, save a new version with Ctrl+Shift+S (e.g. mug_v03.blend) so you can always go back.

    How to read the keys

    Ctrl+R hold the keys together
    SthenZ press one after the other
    Numpad 1 number pad key
    Alt+Left click mouse action

          For tutors

          Teacher notes

          Purpose and audience

          Part 2 of an interactive Blender series for FE and HE students. It is designed for learners who have completed the Blender Shortcut Trainer (Part 1) and can navigate the viewport, switch between Object and Edit Mode, select components and use Extrude, Inset, Bevel and Loop Cut.

          The resource moves from explanation (Learn) through experimentation (Stack lab) and analysis (stack order, topology, which modifier) to decision making (scenarios), retrieval practice (review deck, final challenge) and application in Blender (mini project). The learning outcomes at the top can be copied into a scheme of work.

          How this follows on from Part 1

          Same look and features: the dark Blender-style theme, styled keys, progress indicator, Mac keys toggle, searchable reference, printable cheat sheet, review deck, final challenge and printable summary all work the same way, so students can focus on the content.

          Prerequisite check: the warm-up recaps the Part 1 shortcuts used here (Tab, 1/2/3, G/R/S with axis keys, E, I, Ctrl+R, Ctrl+B, Ctrl+A and Shift+D). Students scoring under 6/8 first time are pointed back to the Shortcut Trainer. Keep both HTML files in the same folder so the link works.

          Progression: Part 1 taught destructive tools (Ctrl+B, E, I). Part 2 introduces non-destructive equivalents (Bevel modifier, Solidify, Array) and the quality of the mesh itself (topology and shading). Part 3 (Materials and Shading) builds on clean topology and smooth shading.

          Suggested session plan (two sessions of about 90 minutes)

          Session 1 — Modifiers

          Starter (10 min): warm-up quiz. Note who scores under 6/8 and pair them with a confident student, or set Part 1 practice.

          Intro (10 min): demonstrate destructive vs non-destructive editing in Blender: bevel a cube with Ctrl+B, then with a Bevel modifier, and change the width afterwards.

          Main (40 min): students work through Learn categories 1–8 with quick checks. Live demo of Mirror with Clipping and of Ctrl+1 to Ctrl+3.

          Practice (20 min): Stack lab goals, then Fix the stack order. Ask students to explain one order choice aloud.

          Plenary (10 min): Which modifier? as a whole-class vote.

          Session 2 — Topology, shading and the project

          Starter (5 min): review deck.

          Main 1 (20 min): Learn categories 9–11, then Spot the topology problem. Show a real mesh with the Statistics overlay and Select › Select All by Trait › Faces by Sides.

          Main 2 (15 min): scenario quiz in pairs, then Common mistakes.

          Main 3 (40 min): coffee mug mini project in Blender.

          Plenary (10 min): final challenge (or set as homework), then print or copy the summary.

          Differentiation

          Support: use the hint buttons, multiple-choice-only mode in the final challenge, the printed cheat sheet, and the Stack lab before working in Blender. Students can complete the mug without the handle (steps 1–7) and still meet the core outcomes. Pair students for the scenario quiz.

          Stretch: press-the-keys questions, the extension tasks (Screw-modifier mug, café table with Mirror and Array, Boolean logo with a topology critique) and the challenge of explaining every modifier order choice in writing. Advanced students can retopologise a Boolean result into clean quads.

          Accessibility: every activity works with a keyboard and screen reader. Reordering uses buttons or arrow keys as well as drag and drop. Diagrams have text descriptions, and feedback is announced.

          Suggested assessment evidence

          Learning summary: printed or copied, showing categories explored, activity scores, project steps, final challenge best score and the reflection.

          Project evidence: a render of the mug, a screenshot of each object’s modifier stack, and a wireframe screenshot with the Statistics overlay on.

          Professional discussion: ask “Why is Mirror above Subdivision Surface?”, “Where did you put support edges, and why?” and “When would you avoid a Boolean?”.

          Possible criteria: Pass — uses at least three modifiers correctly to produce the model. Merit — justifies the stack order and uses support edges to control smoothing. Distinction — produces clean quad topology, evaluates alternative approaches (e.g. Screw vs cylinder, Boolean vs modelled hole) and fixes problems independently.

          Results are self-reported and stored only on the student’s device, so treat them as formative evidence rather than secure assessment.

          Practical and version notes

          The resource is a single HTML file with no external libraries, so it works offline and can be shared through a VLE or shared drive. Progress is stored in the browser’s local storage, so it does not follow students between computers, and locked-down or private browsing may clear it.

          Content is based on Blender 4.x with the default keymap and left-click select. Version notes: 4.1 removed the Auto Smooth checkbox (use Shade Auto Smooth, which adds a Smooth by Angle modifier); 4.2 moved add-ons such as Bool Tool to the Extensions platform; 4.5 added the Manifold Boolean solver.

          The Stack lab is a 2D teaching simulation, not Blender itself. It shows how stack order changes a result, but real meshes are 3D and Blender’s algorithms are more sophisticated. Encourage students to test every idea in Blender as well.
