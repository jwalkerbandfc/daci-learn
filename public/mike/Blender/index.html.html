    Interactive learning activity · Blender 4.x

    Model faster with Blender shortcuts

    Blender is designed to be driven from the keyboard. This resource helps you learn the shortcuts used most often, then practise, recall and apply them in realistic modelling tasks.

    Start learning Jump to practice
    TabGRS XYZE ShiftDF12A

    Learning outcomes

    By the end of this resource you will be able to:

    • navigate the 3D viewport and switch between standard views using the keyboard;
    • select, move, rotate and scale objects precisely using axis locks and typed values;
    • switch between Object and Edit Mode and choose vertex, edge or face selection;
    • use Extrude, Inset, Bevel and Loop Cut to change the shape of a mesh;
    • add, delete and duplicate objects, and explain the difference between Shift+D and Alt+D;
    • recognise and fix common shortcut mistakes;
    • render an image and save your work safely.

    Why learn keyboard shortcuts?

    ⚡Work faster

    Pressing G is quicker than finding the Move tool in a menu. Small savings add up across hundreds of actions in every project.

    ◎Stay focused

    Your eyes stay on the model instead of searching menus, so you keep your creative flow and spot problems sooner.

    ⌖Be precise

    Shortcuts let you lock axes and type exact values, such as GX2 to move exactly 2 units.

    ★Follow tutorials

    Most tutorials and professionals talk in shortcuts. Knowing them makes learning new techniques much easier.

    Before you start

    Mouse position matters

    Blender shortcuts act on the area under your mouse pointer. If a shortcut “doesn’t work”, check the pointer is over the 3D viewport.

    No number pad or middle mouse?

    In Edit › Preferences › Input, turn on Emulate Numpad and Emulate 3 Button Mouse. You can also use the ` View pie menu.

    Using a Mac?

    Some commands, such as save and undo, use Cmd instead of Ctrl, and Alt is labelled Option. Most modelling shortcuts (like Ctrl+B) still use Ctrl.

    Which keymap?

    Shortcuts here use Blender 4.x’s default keymap with left-click select. Other keymaps (e.g. Industry Compatible) differ.

    How to read the keys

    Shift+D hold the keys together
    GthenX press one after the other
    Numpad 1 number pad key
    MMB drag mouse action

        For tutors

        Teacher notes

        Purpose and audience

        A self-paced, interactive resource for FE and HE students who are new to Blender or building confidence. It moves from explanation (Learn) through recall (quizzes, flashcards) to application (practice viewport, mini project), which supports long-term retention better than reading a list of shortcuts.

        The learning outcomes are listed at the top of the page and can be copied into a scheme of work or session plan.

        Suggested session plan (about 2 hours, or split over several sessions)

        Starter (10 min): students read the intro and key terms, then explore the Navigation and Selection categories.

        Main 1 (30 min): work through the remaining Learn categories and quick checks. Pair students to quiz each other using the reference.

        Main 2 (20 min): Common mistakes and the scenario quiz. Discuss the “same key, different mode” table as a class.

        Main 3 (40 min): practice viewport tasks, then the house mini project in Blender.

        Plenary (15 min): final challenge (press-the-keys mode), then students print or copy their summary.

        Following sessions: start with 5 minutes of the review deck to refresh memory.

        Differentiation and stretch

        Support: use the on-screen keys, hints before answers, multiple-choice mode in the final challenge, and the printed cheat sheet.

        Stretch: press-the-keys mode with the timer, the speed run (record best times), and the project extension tasks.

        Evidence and assessment

        The Summary section shows categories explored, quiz scores, tasks and project steps completed, best final score, speed run time and the student’s reflection. Students can print it, save it as a PDF or copy it as text to submit through your learning platform.

        Results are self-reported and stored only on the student’s device, so treat them as formative evidence rather than a secure assessment.

        Practical notes

        The resource is a single HTML file with no external libraries, so it works offline and can be shared through a VLE or shared drive.

        Progress is saved in the browser’s local storage. It will not follow students between computers, and some locked-down or private browsing setups clear it when the window closes.

        Shortcuts are based on Blender 4.x with the default keymap. Check your classroom machines use the default keymap and left-click select.

        Accessibility: keyboard navigation and visible focus throughout, screen-reader labels for keys and the practice viewport, reduced-motion support and high-contrast colours.

        Shortcuts are based on Blender 4.x with the default keymap (left-click select). Check Edit › Preferences › Keymap if a shortcut behaves differently on your computer.
